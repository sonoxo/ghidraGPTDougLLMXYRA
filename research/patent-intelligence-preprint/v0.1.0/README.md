# GPT-DOUG Patent Intelligence Preprint

**Paper:** From Search Sets to Reusable Architectures: A Provenance-Preserving Ontology for AI-Assisted Patent Intelligence in USPTO Patent Public Search

**Author:** Almighty Sonoxo  
**Version:** 0.1.0  
**Date:** 2026-09-21  
**Status:** Public preprint / technical methods paper; not externally peer reviewed.

This public research package contains the manuscript, machine-readable references, and citation metadata. The associated GPT-DOUG ontology is versioned separately as USPTO Patent Public Search Ontology v1.2.0.

The framework explicitly distinguishes patent search hits, patent application/grant claims, preprints, peer-reviewed evidence, independent replication, and regulatory evidence. Patent-derived architecture patterns are retained as sourced inspiration rather than independent scientific validation.

## Research-integrity boundary

- Search-hit count is not analyzed-corpus size.
- Patent publication or grant is not independent scientific validation.
- Explainability is not target validation.
- Source-to-target transfer requires target-side verification.
- This version is a preprint and has not undergone external peer review.
